# Change log

## 1.1.0 — 2026-09-14

- Added a local company-audit dashboard and CLI with persistent SQLite history.
- Added explicit account identity, revision comparisons, human review events and approved-only delivery.
- Added packaged synthetic demos and a universal dependency lock.
- Corrected branch/chain merging, transitive location conflicts and skipped large duplicate blocks.
- Prevented unmatched company websites and lookalike mail domains from confirming contacts.
- Corrected unknown DNS and Null MX handling, ambiguous imports and missing-required-column outcomes.
- Added CSV formula escaping, import limits, output path validation and unique timestamped runs.
- Added public destination and redirect checks, conservative robots handling and final report synchronization.
- Packaged the dashboard for wheel installations and added release checks/documentation.

See `docs/VALIDATION.md` for test evidence and limits. Commercial readiness is scoped to a supervised
local pilot; shared hosting, customer demand and field accuracy require further validation.
